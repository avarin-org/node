# Avarin JOSE

Implementation of the RFCs of the JOSE Working Group.

The following RFCs are implemented by this package:

- [x] [RFC 7515 JSON Web Signature (JWS)](https://www.rfc-editor.org/info/rfc7515/)
- [ ] [RFC 7516 JSON Web Encryption (JWE)](https://www.rfc-editor.org/info/rfc7516/)
- [x] [RFC 7517 JSON Web Key (JWK)](https://www.rfc-editor.org/info/rfc7517/)
- [ ] [RFC 7518 JSON Web Algorithms (JWA)](https://www.rfc-editor.org/info/rfc7518/)
- [ ] [RFC 7519 JSON Web Token (JWT)](https://www.rfc-editor.org/info/rfc7519/)
- [ ] [RFC 7638 JSON Web Key (JWK) Thumbprint](https://www.rfc-editor.org/info/rfc7638/)
- [x] [RFC 7797 JSON Web Signature (JWS) Unencoded Payload Option](https://www.rfc-editor.org/info/rfc7797/)
- [ ] [RFC 8037 CFRG Elliptic Curve Diffie-Hellman (ECDH) and Signatures in JSON Object Signing and Encryption (JOSE)](https://www.rfc-editor.org/info/rfc8037/)
- [ ] [RFC 8812 JSON Object Signing and Encryption (JOSE) Registration for Web Authentication (WebAuthn) Algorithms](https://www.rfc-editor.org/info/rfc8812/)
- [ ] [RFC 9278 JWK Thumbprint URI](https://www.rfc-editor.org/info/rfc9278/)
- [ ] [RFC 9864 Fully-Specified Algorithms for JSON Object Signing and Encryption (JOSE)](https://www.rfc-editor.org/info/rfc9864/)
- [ ] [RFC 9964 ML-DSA for JSON Object Signing and Encryption (JOSE)](https://www.rfc-editor.org/info/rfc9964/)
